# AiGo Preview 7

Version 0.7.8 - build 7008999 - bundle `dev.aigo.preview`.

This preview completes AiGo branding across the native and web surfaces, adds a host-scoped terminal and configured Herdr launcher, preserves the exact host terminal across reconnect and cold launch, and fixes mobile terminal sizing, final-column rendering, mouse input ownership, keyboard controls, and focus-mode reflow.

Workspace processes and saved terminal history remain shared through the host. Selected panes, sidebar state, and layout remain local to each client, so the PC and phone can navigate independently. AiGo does not automatically import, resume, or stop duplicate Pi/Gentle Shell writers.

Sign and install over the existing AiGo Preview with the same signing settings. Leave the custom identifier blank and duplicate installation off. Do not delete the existing app first. Confirm About shows 0.7.8 / AiGo Preview 7. Existing pairing should remain available.

Physical-device acceptance remains pending. Test the issue checklist supplied with the release link; automated and unsigned-artifact checks do not substitute for device acceptance.
