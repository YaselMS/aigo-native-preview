# AiGo Task Chat unsigned test build

Version 0.7.9, build 7009999, bundle `dev.aigo.taskchat.preview`, scheme
`aigo-task-chat`. This is a separate identity from the historical Preview app.

The workflow applies the unchanged native viewer patch to upstream
`9400a49af670fdb5db4af58e73f8df98588dbea9`, then the cumulative
`gentle-task-chat.patch` from development source
`b8e132c10ee78f961415ff481b83ed365f0ef741`. Do not also apply the historical
`gentle-live-client.patch`. Licenses and pinned dependencies are retained.

Dispatch `ios-preview.yml` on this branch. It uses a standard public-repository
macOS runner, read-only repository permission, no signing credentials, no model
calls, no release/deployment, and one-day artifact retention. The artifact is
`aigo-task-chat-0.7.9-unsigned-iphone`; its IPA and manifest are the only outputs.

Sign and install using your existing signing arrangement. Open the new AiGo Task
Chat app and paste a fresh task invitation generated by the matching PC host.
Pairing is off by default. The PC owner explicitly enables one selected task for
one hour; invitations expire after two minutes. Revoke or restart closes access.
Device keys and grants remain in memory; no invitation, host address, credentials,
session transcripts or private runtime data are bundled in this build.

The paired phone can read that task's chat, answer questions and send prompts;
agent coding tools stay scoped to the selected project. It has no direct file
browser, terminal, desktop or daemon-wide access. Physical iPhone acceptance,
full desktop control and locked-phone push alerts remain separate test gates.

The build patch clean-applies to the upstream pin plus the native patch. Its 50
changed package files match the tested source after canonical line-ending
normalization. Root lint passes in that reconstruction. The development tree's
unrelated vendored Gentle source is excluded from this upload, so its existing
lint violations are neither hidden nor carried into CI.
